# 방구석 캠핑장

모닥불 앞에 말없이 앉아 쉬는 온라인 캠핑장. 브라우저 3D(Three.js) + Node 서버(WebSocket).

## 실행

```bash
npm install          # three · ws
node server.mjs      # http://localhost:3000/
```

Windows 에서는 `serve.cmd` 를 실행해도 됨 (`.tools\node` 가 있으면 그 Node 를 씀).

| 환경변수 | 기본 | 뜻 |
|---|---|---|
| `PORT` | `3000` | 포트 |
| `HOST` | `127.0.0.1` | 같은 망·공유기 포트포워딩으로 열려면 `0.0.0.0` |

임시 인터넷 주소가 필요하면 Cloudflare 임시 터널: `cloudflared tunnel --url http://127.0.0.1:3000` (`tunnel.cmd`).

## 구성

| 파일 | 내용 |
|---|---|
| `server.mjs` | 정적 파일(`public/`) · `/vendor/three/`(node_modules) · `/chat` WebSocket(채팅 · 서버2·3 방 · 다른 사람 자리 · 인사) |
| `public/index.html` | 화면 전부 — 캠핑장 지도 · 아바타 · 계절 · 매점 · 소리(Web Audio 합성, 음원 파일 없음) |

## 조작 · 자리

- 모바일: 바닥을 눌러 이동, 한 손가락으로 쓸어 둘러보기, 두 손가락으로 확대/축소합니다.
- 첫 접속에는 임의 닉네임이 채워집니다. 입장 전 입력창이나 입장 후 왼쪽 위 이름을 눌러 변경할 수 있으며, 변경한 이름은 기기에 저장됩니다.
- 방을 변경해도 들어가기를 한 번만 누르면 입장합니다.
- 의자·매트·해먹은 같은 방 안에서 먼저 선택한 사람이 사용합니다. 사용 중인 자리를 선택하면 빈 의자로 이동하고, 모두 차 있으면 현재 위치에서 기다립니다.

검사: `npm test` (새 패키지 설치 없이 Node 기본 테스트 실행기 사용).

## 조용히 쉬거나 함께 쉬기

- 기본 상태는 **조용히 쉬는 중**입니다. 채팅·인사 알림·선물을 받지 않습니다. **말 걸어도 좋아요**로 바꾸면 같은 캠프 사람들과 대화하고 가까운 사람에게 마시멜로를 건넬 수 있습니다.
- **옆자리 초대** 링크는 같은 방으로 연결합니다. 친구가 접속 중이면 가까운 빈 의자를 배정하고, 친구가 없거나 의자가 가득 찼으면 안내합니다. 초대 표시는 해당 브라우저 탭이 살아 있는 동안 유지됩니다.
- **걱정 내려놓기**에 적는 글은 서버에 전송하거나 저장하지 않습니다. 장작 태우기 또는 창 닫기 시 입력이 지워집니다.
- 사진 버튼은 이름·날짜를 넣은 캠핑 엽서를 만듭니다. 미리보기 후 직접 저장하거나 기기의 공유 기능을 사용할 수 있습니다.
- 소리 크기를 조절할 수 있으며 해당 기기에 저장합니다.

## 고정 주소로 클라우드 실행

`npm start`는 기존 로컬 실행입니다. Cloudflare Workers + SQLite Durable Objects용 코드도 포함되어 있어, 배포 후에는 Mac과 임시 터널을 켜둘 필요가 없습니다. 별도 도메인 구매 없이 계정의 `workers.dev` 주소를 사용합니다. 실제 주소는 배포 결과에서 확인해야 합니다.

```bash
npm install
npm test
npx wrangler@4.156.0 login
npm run deploy:cloud
```

- 빌드: `npm run build:cloud` — 정적 화면과 Three.js를 `.build/site`에 복사합니다.
- 로컬 클라우드 개발: `npm run dev:cloud`.
- 배포 준비 검증: `npm run build:cloud` 후 `npx wrangler@4.156.0 deploy --dry-run`.
- WebSocket 방 상태·자리·휴식 상태는 hibernation attachment로 복원합니다. 채팅 기록은 보관하지 않습니다.
- `wrangler.jsonc`의 프로젝트 이름은 `bangguseok-camp`입니다. 계정 인증 및 해당 이름의 실제 배포 성공 전에는 고정 주소가 생긴 것이 아닙니다.
- 무료 제공량에는 한도가 있습니다. 대규모 홍보 전에 실제 기기·동시 접속 부하·계정 사용량을 확인해야 하며, 6만 명 규모는 검증하지 않았습니다.

## 이용 횟수 확인

`/stats`는 UTC 기준 오늘의 방별 합계입니다. `entries`는 입장 세션, `returningEntries`는 기기에 이전 날짜 방문 기록이 있는 입장, `engaged`는 전면 화면에서 연결된 채 5분 이용한 세션, `inviteEntries`는 초대 링크 입장, `gifts`는 실제 전달한 선물 횟수입니다. 고유 방문자 수가 아니며 새로고침·재연결·날짜 경계를 고려해 해석해야 합니다.

집계에는 이름·채팅·걱정 글·IP·방문자별 기록을 넣지 않습니다. 이전 방문 날짜는 기기에만 저장하며, 서버에는 재방문 여부와 합계만 보냅니다. 로컬 실행은 `.data/camp-metrics.json`, 클라우드는 방별 Durable Object 저장소에 오늘의 합계를 보관합니다. 공개된 합계 API이므로 의도적인 조작을 막는 정밀 분석 도구로 사용하지 마세요.
